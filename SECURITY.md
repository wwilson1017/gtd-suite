# Security

Report vulnerabilities privately using GitHub's **Report a vulnerability** button on the
repository's **Security** tab. Do not open a public issue for a vulnerability.

Include the affected version, steps to reproduce, the expected and actual behaviour, and
what an attacker could do. A small proof of concept helps. Do not include real tokens,
passwords or other people's data.

There is no bounty. Fixes go out in the next dated release.
